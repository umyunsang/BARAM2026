## 3. Data Leakage 방지 규칙
- 본 대회는 예측기준시점에 실제로 활용 가능했던 정보만을 사용하여 발전량을 예측하는 것을 원칙으로 합니다.
- 참가자는 각 예측값을 산출할 때 아래 기준을 반드시 준수해야 합니다.

[기본 원칙]
- 각 예측값에는 해당 예측값의 예측기준시점 전에 생성·공개·확정되어 실제로 활용 가능했던 정보만 사용할 수 있습니다.
- 데이터의 사용 가능 여부는 데이터가 가리키는 대상 시각이 아니라, 해당 데이터가 생성·공개·확정되어 실제로 활용 가능해진 시각을 기준으로 판단합니다.
- 예측기준시점 이후에 관측·생성·공개·확정된 정보는, 해당 정보가 예측 대상 시각에 대한 정보이더라도 사용할 수 없습니다.

[예측기준시점의 정의] (*)자주듣는질문으로 8/3 17:00 추가 기재
- 각 예측 대상일의 발전량은 해당 일자의 전일 14:00 (KST)을 예측기준시점으로 합니다.
- 동일한 예측 대상일에 포함된 모든 시간대의 발전량에는 동일한 예측기준시점이 적용됩니다.
- 예를 들어, 2025년 1월 13일 00:00부터 23:00까지의 발전량을 예측하는 경우, 모든 예측 행의 예측기준시점은 2025년 1월 12일 14:00입니다.
- 따라서 각 예측값을 산출할 때에는 해당 예측기준시점 이전에 실제로 생성·공개·확정되어 활용 가능했던 정보만 사용할 수 있습니다.
- 데이터 사용 가능 여부는 '2025년 이전에 공개되었는지'와 같이 특정 연도를 기준으로 일괄 판단하지 않으며, 각 예측 행에 적용되는 예측기준시점을 기준으로 판단합니다.

[예보 데이터 사용 기준]
- 기상예보 데이터는 예보 대상 시각이 아니라 예보가 생성·공개되어 실제로 활용 가능해진 시각을 기준으로 사용 가능 여부를 판단합니다.
- 예측기준시점 이후에 생성·공개된 예보자료는 사용할 수 없습니다.
- 예를 들어, 2025년 1월 13일 10:00의 발전량을 예측하는 행의 예측기준시점이 2025년 1월 12일 14:00인 경우, 2025년 1월 13일 00:00에 생성·공개된 2025년 1월 13일 10:00 대상 예보 데이터는 사용할 수 없습니다.

[실측 데이터 사용 기준]
- 기상 관측자료 등 실측 데이터는 예측기준시점 전에 이미 관측·공개·확정된 과거 자료에 한해 사용할 수 있습니다.
- 예측기준시점 이후에 관측·생성·공개·확정된 실측값, 사후 보정자료 또는 재분석자료는 사용할 수 없습니다.

[금지 정보]
- 평가 구간의 실제 발전량, 실측 운영 데이터, 비공개 운영 데이터 또는 정답에 준하는 정보는 사용할 수 없습니다.
- 평가 데이터의 실제 정답 또는 정답에 준하는 정보를 비공식적으로 수집하여 직·간접적으로 활용하는 모든 행위는 금지되며, 적발 시 즉시 실격에 해당합니다.
- 파생 변수, 통계값, 보간값, 집계값 등을 생성하는 경우에도 예측기준시점 이후의 정보가 포함되어서는 안 됩니다.

[소명 및 제재]
- 참가자는 사용한 데이터와 전처리·학습·추론 과정이 위 규칙을 준수했음을 코드 검증 및 2차 평가 과정에서 설명할 수 있어야 합니다.
- 위 규칙을 위반한 정보 활용이 확인되거나, 사용 데이터 및 산출 과정에 대한 소명이 충분하지 않은 경우 평가 대상에서 제외될 수 있습니다.

## 4. 외부 데이터 사용 규칙
[사용 가능 기준]
- 법적 제약이 없어야 합니다.
- 저작권·라이선스·개인정보·이용 약관을 위반하지 않아야 합니다.
- 누구나 접근 가능한 공개 데이터여야 합니다.
- Data Leakage 방지 규칙을 준수해야 합니다.

[사용 제한 기준]
- 특정 기관, 기업, 개인 등 제한된 주체만 접근 가능한 비공개 데이터 또는 내부 운영 데이터는 사용할 수 없습니다.
- 평가 데이터의 정답 또는 정답에 준하는 정보를 포함하거나 유추할 수 있는 데이터는 사용할 수 없습니다.

[제출 및 재현 의무]
- 2차 평가 대상자로 지정되는 경우, 참가자는 코드 검증 및 2차 평가를 위해 모델 학습과 추론에 사용한 모든 외부 데이터 파일, 데이터 출처, 수집 방법, 수집 시점, 사용 기간, 사용 변수, 라이선스, 전처리 코드 등을 성실하게 제출해야 합니다.
- 외부 데이터는 제출된 코드와 자료만으로 재현 가능해야 합니다.
- 외부 데이터의 생성·공개·확정 시점이 각 예측값의 예측기준시점 전임을 설명할 수 있어야 합니다.
- 외부 데이터의 출처, 수집·전처리 과정, 활용 가능 시점 또는 재현 가능성이 충분히 소명되지 않는 경우 평가 대상에서 제외될 수 있습니다.

## 5. 사전 학습모델 사용 규칙
- 2026년 7월 6일 전, 즉 2026년 7월 5일까지 공식적으로 가중치가 공개된 오픈소스 모델만 사용할 수 있습니다.
- 오픈소스 라이선스 모델이란 모델 가중치의 사용, 수정, 배포, 재배포 및 상업적 이용이 허용되는 라이선스로 공개된 모델을 의미합니다.
- 단순히 가중치가 공개되어 있더라도, 비상업적 이용·연구 목적·평가 목적 등으로 사용 범위가 제한된 모델은 사용할 수 없습니다.
- 해당 조건을 충족하지 않는 모델은 사용할 수 없습니다.
- 사용한 모델, 가중치, 라이선스, 다운로드 경로 등은 코드 검증 및 2차 평가 과정에서 확인될 수 있습니다.

## 6. API 기반 모델 사용 제한
- OpenAI API, Gemini API, Hugging Face Inference API, Together AI, OpenRouter 등 원격 서버를 통해 모델 응답을 받는 API 기반 모델 사용은 불가능합니다.
- 외부 API를 통한 모델 추론은 금지되며, 참가자가 직접 관리하는 PC·클라우드 서버·연구실 서버 등에서 모델 가중치를 직접 로드하여 실행하는 방식만 허용됩니다.
