# M281 — `EXTERNAL_NWP_ARCHIVE_DOES_NOT_COVER_VALIDATION_SURFACE` 전제 재검정

- 판정일 2026-08-06 · 노드 `C1N103_EXTERNAL_NWP_MEMBER` (PRUNED) 의 부활조건 검사
- **적합 0회 / 락박스 미접근 / 라벨 미사용 / 제출 없음.** 공개 API 가용성 조회만 수행.

## 1. 왜 재검정했나

`m271_p4_consolidate` 가 조합 축의 부활조건을 명시했다 —
> 남는 경로는 둘뿐이다 — (1) M244 의 검색 키 복원, (2) **다른 NWP 를 독립 앙상블 멤버로** 도입.
> 상관 <= 0.85 이면서 품질 > 0.6058 인 멤버가 생기면 뒤집힌다.

C1N51 측정에서 외부 소스의 공급원 대비 상관은 `icon_global` 0.836/0.808/0.783,
`ecmwf_ifs025` 0.780/0.759/0.746 로 **전부 0.85 미만**이다. 즉 다양성 조건은 이미 충족 가능하다.
차단 사유는 오직 **검증면 미커버**였다.

## 3. 판정 — 전제 유지, 노드 폐기 상태 유지

누출안전 변수(`previous_day2`, 48h 리드)는 **2023 을 전혀 덮지 않는다.**
2023 에 존재하는 것은 best-match 단기예보뿐이며, 이는 예측기준시점(D-1 14:00 KST) 이후에
생성된 예보를 포함하므로 **대회 규칙상 사용 불가**다.

2025(평가기간)는 양 모델 모두 누출안전 변수가 **완전히 존재**한다. 그러나
**검증 없이 배포할 수는 없다** — 유일한 대안 검증면인 2024 는 2 회 소진된 락박스다.

따라서 축은 두 독립 근거로 닫힌다.

1. sigma 감소량 부족 — 2024 에서 `scada_ws` 기준 실측 3.9~6.1% 대 필요 13.3% (C1N52)
2. **누출안전 검증면 부재** — 2023 미커버 (본 재검정)

`EXTERNAL_NWP_ARCHIVE_DOES_NOT_COVER_VALIDATION_SURFACE` 는 **참으로 유지**되고
`C1N103_EXTERNAL_NWP_MEMBER` 는 PRUNED 상태를 유지한다.

## 4. 기록해 둘 비대칭

평가기간에는 누출안전 외부 NWP 가 있고 검증면에는 없다. 이 비대칭은 데이터 제공자의
아카이브 보존정책에서 오며 모델링으로 해소되지 않는다. 향후 대회에서 외부 NWP 를 쓰려면
**대회 기간 중 실시간으로 예보를 축적**해야 한다 — 사후 수집으로는 검증면을 복원할 수 없다.
