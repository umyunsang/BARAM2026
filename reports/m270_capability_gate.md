## 축 1 — 신규 의존성

### 증거

- 런타임: 프로젝트 로컬 `.venv`, Python 3.12
- 설치 경로 도달 가능: PyPI 조회 성공 (`ngboost` 최신 `0.5.11` 확인)
- 현재 설치: `lightgbm 4.7.0`, `xgboost 3.3.0`, `catboost 1.2.10`, `scikit-learn 1.9.0`, `numpy 2.5.1`, `scipy 1.18.0`, `pandas 2.3.3`, `pyarrow 23.0.1`
- 미설치: `torch`, `ngboost`

### 공식 규칙 대조

공식 규칙은 언어(Python)와 **로컬 실행**만 요구한다. 라이브러리 설치에 대한 제한은 없다. 사전학습 *가중치*의 2026-07-05 공개일 규칙은 **모델 가중치에만** 적용되며 일반 라이브러리에는 적용되지 않는다.

### 프레임워크 선정 (사용자 요구: 검증된 프레임워크 기반)

직접 만든 `experiment_graph.json` + 자체 빌더를 **검증된 라이브러리 기반으로 교체**한다.

| 역할 | 채택 | 버전 | 라이선스 | 선정 이유 |
|---|---|---|---|---|
| 그래프 엔지니어링 | **NetworkX** | 3.6.1 | BSD-3-Clause | 순수 파이썬, 데몬·서버 없음, 결정적. `descendants()`/`ancestors()`로 prune 전파와 전제 의존 추적을 표준 연산으로 처리 |
| 루프 엔지니어링 | **Optuna** | 4.9.0 | MIT | **ask-and-tell API**가 이 프로젝트의 규율과 정확히 일치. 영속 study(SQLite)로 세션 중단 복구(R5), 샘플러 시드 고정으로 결정성 |

**Optuna를 쓰되 자동 탐색은 쓰지 않는다.** `study.ask()`로 실험을 예고하고, 동결된 게이트 아래 1회 실행한 뒤, `study.tell()`로 결과를 보고한다. 즉 예고→게이트→1회 실행→재현 규율은 그대로 두고 **루프 부기와 선택만 검증된 라이브러리에 위임**한다. 하이퍼파라미터 자동 탐색으로 전환하면 이 프로젝트가 반복적으로 경계해 온 동일-fold 과적합을 다시 불러들이므로 금지한다.

## 축 2 — 외부 공개 데이터

### 결정적 제약 — 예측기준시점

불변 아카이브 `test/gfs_test.csv`에서 직접 확인:

- `data_available_kst_dtm`: **365개**, `2024-12-31 13:00` ~ `2025-12-30 13:00` KST (매일 13:00)
- `forecast_kst_dtm`: `2025-01-01 01:00` ~ `2026-01-01 00:00` (8,760시간)

즉 **기준시점 = 매일 13:00 KST = 04:00 UTC**, 리드 12~36시간.

공식 규칙은 "대상 시각이 아니라 **생성·공개·확정되어 실제로 활용 가능해진 시각**" 기준이다. 따라서 외부 NWP는 **04:00 UTC 이전에 발표 완료된 런**만 사용 가능하다.

### 가용시각 마진 설계

GFS/GEFS 00Z 런은 통상 03:30~05:00 UTC에 배포되어 **경계선**이다. 소명 위험을 지지 않기 위해 **전일 18Z 런**을 사용한다.

| 항목 | 값 |
|---|---|
| 사용 사이클 | 전일(D−1) 18Z |
| 발표 시각 | 18:00 UTC D−1 |
| 기준시점 | 04:00 UTC D |
| **마진** | **약 10시간** |
| 필요 리드 | +22h ~ +45h |
| GEFS 예보 길이 | 16일 |

성능상 최신 런이 유리하지만 **소명 가능성을 위해 마진을 산다.** R2(실격 리스크)를 고려하면 옳은 거래다.

### 적격성 증거 — NOAA GEFS

| 기준 | 증거 | 충족 |
|---|---|---|
| 누구나 접근 가능한 공개 데이터 | 버킷 `noaa-gefs-pds`를 **자격증명 없이** HTTPS 목록 조회 성공 (`--no-sign-request`) | ✅ |
| 법적 제약·라이선스 | NOAA NODD: "open to the public and can be used as desired". 저작권 주장 없음, 출처 표기 요청 | ✅ |
| **가용시각 증명 가능** | 키 경로가 `gefs.YYYYMMDD/CC/`, `CC ∈ {00,06,12,18}` — **발표 사이클이 객체 키에 직접 포함** | ✅ |
| 기간 커버리지 | `gefs.20220401/` 및 `gefs.20250101/` 존재 확인 → 학습·테스트 전 구간 | ✅ |
| 재현 가능한 수집 | 결정적 S3 키, HTTPS 익명 접근, 수집 스크립트로 재현 가능 | ✅ |
| 비용 | 무료, requester-pays 아님 | ✅ |

`gefs.YYYYMMDD/CC/` 구조가 이 축의 핵심이다. 가용시각을 **서술로 주장**하는 것이 아니라 **객체 키로 입증**할 수 있다.

### 왜 GEFS인가 (진단과의 연결)

공급된 GFS/LDAPS는 결정론적 단일 실행이다. M269가 진단한 결함은 **조건부 분포의 예리함 부족**인데, 앙상블 스프레드는 "지금 이 시각의 예보가 얼마나 불확실한가"를 물리적으로 알려주는 공변량이다. 현재 피처 집합에는 이 신호가 구조적으로 부재한다. GFS를 추가하는 것은 중복이지만 **앙상블은 새로운 정보 축**이다.

### 필수 소명 대장 (사용 시 유지)

출처 URL, 버킷·키 경로, 사이클 시각, 수집 시점, 사용 변수, 라이선스, 전처리 코드. 2차 평가 제출 대상.

### 금지 사항 재확인

재분석(ERA5 등)·사후보정 자료는 **기준시점 이후 확정**이므로 사용 불가. 실측 관측도 기준시점 이전 확정분만 가능.

**판정: PASS (전일 사이클 한정, 소명 대장 유지 조건)**

## 축 3 — 사전학습 가중치

### 규칙

2026-07-05까지 공개 + **상업적 이용·수정·배포·재배포가 허용되는 OSS 라이선스**. 비상업적·연구전용·평가전용 제한 모델은 사용 불가. 원격 API 추론 금지, 로컬 가중치 로드만 허용.

### 검증 결과 (Hugging Face API 조회)

Moirai 계열은 비상업적 라이선스이므로 공식 규칙에 정면으로 걸린다. 가정하지 않고 확인해서 걸러낸 사례다.

### 증거 강도에 대한 단서

`createdAt`은 Hugging Face **저장소 생성일**이며 공식 발표일과 엄밀히 같지는 않다. 다만 적격 모델 전부가 2024년으로 기준일(2026-07-05) 대비 약 19개월 여유가 있어, 해석을 느슨하게 잡아도 결론은 변하지 않는다. 실제 채택 시 모델 카드·릴리스 노트로 재확인한다.

### 적격성과 유용성의 분리

이 모델들은 **시계열 이력으로부터** 예측한다. 이 과제는 NWP 공변량이 주어진 12~36시간 리드 회귀이며, 대상 구간의 과거 발전량은 추론 시점에 존재하지 않는다. 따라서 제로샷 적용 가능성은 제한적이다. M269가 진단한 결함(공변량 조건부 분포의 예리함)에는 **분포형 학습**(NGBoost·CRPS 손실·분포형 신경망)이 더 직접적이다.

→ 축 3은 **적격이지만 우선순위는 낮다.** 채택 결정은 P1 리서치로 넘긴다.

**판정: PASS (Apache-2.0 모델 한정, Moirai 계열 금지)**
