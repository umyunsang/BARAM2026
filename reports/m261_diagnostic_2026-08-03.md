# M261 full-history strict-classifier diagnostic

## Technical summary

M261 is a deterministic, submission-valid score-feedback candidate built from the independent M107/M102 metric-aware classifier lineage. It is not a demonstrated score improvement. The candidate freezes all feature, model, action, and temporal parameters from pre-2024 Q2 evidence, then fits on all supplied 2022-2024 labels without calculating a 2024 metric. Two complete executions reproduced every persisted output byte-for-byte.

The resulting file is `artifacts/submissions/submission_M261.csv`, SHA-256 `fb937f77dfe501b4d7f8e52da098f07f79b1924dace347d3020da405b660773b`. ## The model is an independent metric-aware classifier deployment

M261 uses the M102 feature representation and decision rule rather than the v2-plus-analog family used by M252. The frozen model specification is:

- 100 Q2-selected weather, geometry, calendar, and cross-fitted site-wind features;
- normalized target bins of width `0.02`, yielding 46 active classes;
- deterministic LightGBM multiclass classification with 60 trees, learning rate `0.025`, 15 leaves, minimum child size 80, and six workers;
- generation-proportional sample weighting with power `1.0`;
- fixed settlement-aware action policy `T0.5_G1.5`;
- fixed temporal policy: group 1 uses shift `-1` with original weight `0.7`; groups 2 and 3 use shift `-2` with original weight `0.8`.

Class centers and group mean generation are estimated during the allowed full-history final fit. They are model parameters. The runner never predicts the training power target for scoring and never compares a 2024 prediction with a 2024 label.

## Site-wind proxies remain inference-safe

## Supplied LDAPS gaps required a label-free deployment repair

Official test GFS contains no missing numeric weather value cells. Official test LDAPS contains 752 missing cells across 19 variables at three forecast times. Several vector components are missing on all 16 grids, which makes the original geometric feature builder fail rather than silently emit an invalid vector field.

M261 repairs only those supplied NWP cells by linear interpolation over adjacent lead hours within the same issuance and grid, with bidirectional edge fill. This is an inference-time weather operation: it uses no generation label, SCADA observation, online score, external data, or cross-issuance value. The runner asserts zero unresolved cells and records the complete variable-level missing map in the receipt.

This repair is necessary for the frozen geometric features but remains a deployment assumption. Its score effect is unknown because test labels are unavailable and 2024 was not reopened for surrogate selection.

## Limitations and decision boundary

M107's strict pooled development Total `0.6268876959` is lineage evidence, not an estimate of M261's DACON score. M261 changes the fit horizon, class centers, group means, teacher models, and test weather year, so development performance cannot be copied onto the final candidate. Likewise, deterministic construction does not imply accuracy.

The M252 online result shows the size of the remaining gap: `0.0331215908` to the formal `0.66000` threshold. M261's independent architecture is valuable for score feedback and possible future diversity analysis, but no local evidence supports claiming it will close that gap.

## Recommended next step

The only decision-enabling next measurement is a user-side DACON upload of the byte-pinned M261 CSV followed by read-only capture of Total, 1-NMAE, FICR, submission ID, and rank. Until that feedback exists, M261 must not be promoted, rejected, blended, or calibrated from its unlabeled 2025 predictions.

If M261 misses the target, the next local experiment must be predeclared from the observed component failure mode and must remain independent of 2024 labels. If it improves FICR but loses 1-NMAE, the next lane should address calibration/point accuracy; if it improves 1-NMAE but loses FICR, the next lane should address settlement-tier mass. A static blend should not be chosen without chronology-safe OOF evidence or external score feedback sufficient to identify a bounded blend hypothesis.
